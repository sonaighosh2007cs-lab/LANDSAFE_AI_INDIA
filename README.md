🌍 Landslide AI Tracking System

Analyse Early • Take Action • Save Life 🚨

The Landslide AI Tracking System is an intelligent early-warning solution designed to help users identify potential landslide risks before they become critical.

Our system continuously analyses important environmental parameters such as:

- 🌱 Soil Condition
- 💧 Humidity
- 🌧️ Rainfall
- 🌡️ Temperature

By combining these parameters with AI-based analysis, the system aims to detect abnormal environmental conditions and provide an early landslide risk warning.
